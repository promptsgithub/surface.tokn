# Branding

Brand tokens and copy rules for student-built surfaces.

## Files

- `BRAND-TOKENS.yaml` - the color palette (signal, board, ink, success).
- See `docs/branding.md` for the full rules.

## The rules in one line

prompts.ai first, then .tokn. No em-dashes or en-dashes. Posture language is
sovereign intelligence, never topology. Palette: signal `#3d78d9`, board
`#13151b`, ink `#e6e8ec`, success `#22c55e`.

## Palette

| Token | Value | Use |
|---|---|---|
| `signal` | `#3d78d9` | Primary accent |
| `board` | `#13151b` | Background (quantum chalkboard) |
| `ink` | `#e6e8ec` | Primary text |
| `success` | `#22c55e` | Success state |

`light_blue` (`#6ea8fe`) is secondary accent only. The retired teal
(`#14b8a6`) is listed for reference and must not be used as a chalkboard
accent.
